# 称重表格多状态显示 — 角标方案实施说明

> 目标文件：`weigh_grid_screen.dart`（提供了原始内容，本文档基于其当前代码给出可直接套用的改动）。
> 涉及但未提供完整内容的文件：`weight_plugin.dart`（定义 `BirdCellState` / `AbnormalDirection`）、`grid_color_config.dart`（定义 `GridColorConfig` / `CellDisplayMode`）——实施前请先核对其中的真实定义，与本文档假设不一致处以仓库实际代码为准。

## 1. 背景

当前 `_resolveState()` 是按优先级 if-chain 返回**单个** `BirdCellState`：

```dart
BirdCellState _resolveState({
  required bool isOverdue,
  required AbnormalDirection abnormalDirection,
  required bool isWeighedToday,
  required bool isWeaning,
}) {
  if (isOverdue) return BirdCellState.overdue;
  if (abnormalDirection == AbnormalDirection.high) return BirdCellState.abnormalHigh;
  if (abnormalDirection == AbnormalDirection.low) return BirdCellState.abnormalLow;
  if (isWeighedToday) return BirdCellState.weighedToday;
  if (isWeaning) return BirdCellState.weaning;
  return BirdCellState.normal;
}
```

优先级（高→低）：超期未称 > 体重偏高 > 体重偏低 > 今日已称 > 断奶期 > 正常。

**问题**：一只鸟可能同时满足多个条件（如超期 + 偏高 + 断奶），但只会展示优先级最高的那一个，其余状态信息直接丢失，巡检人员看不到完整情况。

## 2. 设计目标

1. **主状态视觉完全不变**：继续复用 `colorConfig.borderColor()` / `displayMode` / `fillOpacity` / `borderWidth`，不修改 `GridColorConfig` 本身，不影响现有左边框/填充逻辑。
2. **次要状态用固定角标露出**：在单元格右上角叠加一个绝对定位的小角标，最多显示 2 个次要状态，角标尺寸固定（约 5×12px），**不参与 Row 布局、不随列宽变化、不挤占鸟名/戒指号/体重的显示空间**——这是本方案与"行内加点"/"分段边框"等备选方案的核心区别，专门解决窄列宽（最小 152px）下的空间冲突问题。
3. **断奶期用空心虚线圆**，其余状态用实心圆，呼应断奶期"保持原边框风格"的既有约定，避免与体重偏高（同色系）混淆。

## 3. 状态颜色参考表（不变，仅供核对）

| 优先级 | 状态 | 默认色 |
|---|---|---|
| 1（最高） | 超期未称 | 棕色 |
| 2 | 体重偏高 | 橙色 |
| 3 | 体重偏低 | 软红 |
| 4 | 今日已称 | 绿色 |
| 5 | 断奶期 | 橙色（虚线边框风格） |
| — | 正常 | 透明 |

## 4. 具体改动

### 4.1 删除 `_resolveState`，新增 `_resolveStates`

```dart
/// 按优先级解析全部命中的单元格状态（已排序，第一个即主状态）。
/// 优先级：超期 > 体重偏高 > 体重偏低 > 今日已称 > 断奶期。
List<BirdCellState> _resolveStates({
  required bool isOverdue,
  required AbnormalDirection abnormalDirection,
  required bool isWeighedToday,
  required bool isWeaning,
}) {
  final states = <BirdCellState>[];
  if (isOverdue) states.add(BirdCellState.overdue);
  if (abnormalDirection == AbnormalDirection.high) states.add(BirdCellState.abnormalHigh);
  if (abnormalDirection == AbnormalDirection.low) states.add(BirdCellState.abnormalLow);
  if (isWeighedToday) states.add(BirdCellState.weighedToday);
  if (isWeaning) states.add(BirdCellState.weaning);
  return states;
}
```

### 4.2 新增 `_CornerBadge`（放在 `_BirdCell` 类定义之前或之后均可，同文件内）

```dart
/// 固定在单元格右上角的小角标，展示被主状态"压缩"掉的次要状态。
/// 绝对定位，不参与 Row 布局，尺寸固定，不随列宽变化。
class _CornerBadge extends StatelessWidget {
  final List<BirdCellState> states; // 已经是次要状态列表，最多 2 个
  final GridColorConfig colorConfig;

  const _CornerBadge({required this.states, required this.colorConfig});

  @override
  Widget build(BuildContext context) {
    return Column(
      mainAxisSize: MainAxisSize.min,
      children: states.map((s) {
        final c = colorConfig.borderColor(s);
        final isWeaning = s == BirdCellState.weaning;
        return Container(
          width: 5,
          height: 5,
          margin: const EdgeInsets.only(bottom: 2),
          decoration: BoxDecoration(
            shape: BoxShape.circle,
            color: isWeaning ? null : c,
            border: isWeaning ? Border.all(color: c, width: 1.2) : null,
          ),
        );
      }).toList(),
    );
  }
}
```

### 4.3 改 `_BirdCell.build()`：用 `Stack` 包住原 `Container`，叠加角标

完整替换后的 `_BirdCell` 类（其余字段/构造函数不变，只列 `build()`）：

```dart
@override
Widget build(BuildContext context) {
  final activeStates = _resolveStates(
    isOverdue: isOverdue,
    abnormalDirection: abnormalDirection,
    isWeighedToday: isWeighedToday,
    isWeaning: isWeaning,
  );
  final cellState = activeStates.isEmpty ? BirdCellState.normal : activeStates.first;
  final secondaryStates = activeStates.length > 1
      ? activeStates.sublist(1, activeStates.length > 3 ? 3 : activeStates.length)
      : const <BirdCellState>[];
  final stateColor = cellState == BirdCellState.normal
      ? null
      : colorConfig.borderColor(cellState);
  final mode = colorConfig.displayMode;

  // 背景色（不变）
  Color? bgColor;
  if (isSelected) {
    bgColor = scheme.primaryContainer.withAlpha(60);
  } else if (stateColor != null &&
      (mode == CellDisplayMode.fill || mode == CellDisplayMode.borderAndFill)) {
    bgColor = stateColor.withValues(alpha: colorConfig.fillOpacity);
  }

  // 边框（不变）
  BorderSide border(BorderSide fallback) {
    if (isSelected) {
      return BorderSide(color: scheme.primary, width: 2.5);
    }
    if (stateColor != null &&
        (mode == CellDisplayMode.border || mode == CellDisplayMode.borderAndFill)) {
      return BorderSide(color: stateColor, width: colorConfig.borderWidth);
    }
    return fallback;
  }

  return InkWell(
    onTap: onTap,
    child: Stack(
      clipBehavior: Clip.none,
      children: [
        Container(
          padding: const EdgeInsets.symmetric(vertical: 6, horizontal: 8),
          decoration: BoxDecoration(
            color: bgColor,
            border: Border(
              left: isSelected
                  ? BorderSide(color: scheme.primary, width: 2.5)
                  : (stateColor != null &&
                          (mode == CellDisplayMode.border || mode == CellDisplayMode.borderAndFill))
                      ? BorderSide(color: stateColor, width: colorConfig.borderWidth)
                      : BorderSide.none,
              top: border(BorderSide(color: scheme.outlineVariant.withAlpha(30), width: 0.5)),
              right: border(BorderSide.none),
              bottom: border(BorderSide(color: scheme.outlineVariant.withAlpha(30), width: 0.5)),
            ),
          ),
          child: Row(
            children: [
              Text(
                bird.growthStage == '雏鸟' ? '🐣' : bird.growthStage == '幼鸟' ? '🐤' : '🦜',
                style: const TextStyle(fontSize: 11),
              ),
              const SizedBox(width: 5),
              Expanded(
                child: Text.rich(
                  TextSpan(
                    children: [
                      TextSpan(
                        text: bird.bird.name,
                        style: theme.textTheme.bodySmall?.copyWith(
                          fontWeight: FontWeight.w600,
                          color: isSelected ? scheme.primary : scheme.onSurface,
                        ),
                      ),
                      if (bird.bird.ringNumber != null)
                        TextSpan(
                          text: ' #${bird.bird.ringNumber}',
                          style: TextStyle(
                            fontSize: 10,
                            color: (isSelected ? scheme.primary : scheme.onSurface).withAlpha(140),
                          ),
                        ),
                    ],
                  ),
                  overflow: TextOverflow.ellipsis,
                ),
              ),
              if (latestWeight != null)
                Padding(
                  padding: const EdgeInsets.only(left: 4),
                  child: Text(
                    '${latestWeight!.weightG.toStringAsFixed(1)}g',
                    style: TextStyle(
                      fontSize: 11,
                      fontWeight: FontWeight.w600,
                      color: (isSelected ? scheme.primary : scheme.onSurface).withAlpha(180),
                    ),
                  ),
                ),
              if (isSelected)
                Padding(
                  padding: const EdgeInsets.only(left: 4),
                  child: Icon(Icons.edit, size: 12, color: scheme.primary),
                ),
            ],
          ),
        ),
        if (secondaryStates.isNotEmpty)
          Positioned(
            top: 3,
            right: 3,
            child: _CornerBadge(states: secondaryStates, colorConfig: colorConfig),
          ),
      ],
    ),
  );
}
```

**改动要点**：原 `Container` 及其内部 `Row` 内容**逐字不变**，只是从 `InkWell` 的直接子节点变成 `Stack` 的第一个子节点；新增的 `Positioned` 角标是第二个子节点。`Stack` 默认按非定位子节点（即原 `Container`）确定尺寸，所以单元格整体尺寸、点击区域不受影响。角标用 `top: 3, right: 3` 内嵌在单元格边界以内，不会溢出，因此不需要也不依赖父级的裁切设置。

## 5. 涉及但未提供的文件——实施前请核对

### `weight_plugin.dart`
- 确认 `BirdCellState` 枚举中确实有 `overdue / abnormalHigh / abnormalLow / weighedToday / weaning / normal` 六个值（命名以实际代码为准，若不同请同步替换本文档代码中的引用）。
- 本次改动不需要新增枚举值，也不需要改动 `isLatestAbnormalDirection` / `isWeaningPhase` 等函数，只是消费方式从"取一个"变成"取列表"。

### `grid_color_config.dart`
- 不需要修改。`borderColor(BirdCellState)` 继续按单个状态查色，角标对每个次要状态分别调用一次即可。
- `secondaryStates` 来源于 `activeStates.skip` 后的子集，`activeStates` 本身不包含 `normal`，所以不会把 `normal` 传给 `borderColor`，不需要额外的空值兜底。

## 6. 边界情况 / 验收清单

- [ ] 0 个次要状态（命中 0 或 1 个条件）：不渲染 `_CornerBadge`，单元格外观与改动前**完全一致**。
- [ ] 恰好 1 个次要状态：角标显示 1 个圆点。
- [ ] 2 个或以上次要状态：角标最多显示 2 个（取优先级最高的前两个），不做"+N"计数提示。
- [ ] 次要状态包含断奶期：渲染为空心虚线圆，其余为实心圆。
- [ ] 列宽从 152px（最小）到任意更宽宽度：角标尺寸、位置不随 `width` 变化。
- [ ] 选中态（`isSelected == true`）：角标与选中态的边框/背景变化互不冲突，角标始终叠加在最上层。
- [ ] 表格横向滚动、点击选中/取消选中、保存称重后自动跳转下一只等现有交互**不受影响**（本次改动不涉及这些逻辑，只动 `_BirdCell` 内部渲染）。

## 7. 不在本次改动范围内

- `GridColorConfig` 的 `displayMode` / `fillOpacity` / `borderWidth` 语义不变。
- `_Legend` 图例组件不变（图例本身是逐项列出，不存在压缩问题）。
- `WeighGridNotifier` / `WeighGridState` 中状态计算逻辑（`abnormalDirections` / `weaningBirdIds` / `weighedTodayBirdIds` / `overdueBirdIds` 的来源）不变，只是消费侧从"选一个"变成"列全部"。
